# SpaceFinance

A decentralized infrastructure financing protocol built on Creditcoin (CC3), enabling node operators to access collateral-backed loans and clients to pay for compute services with on-chain proof verification.

## Overview

SpaceFinance connects DePIN node operators with liquidity providers through a trustless lending mechanism secured by the Attestcoin Protocol (formerly USC) cross-chain proofs.

## Tech Stack

- **Smart Contracts**: Solidity (Sepolia + CC3 Testnet/Mainnet)
- **Frontend**: Next.js 14, wagmi, viem
- **Cross-chain**: Creditcoin Attestcoin Protocol + ProofBuilder
